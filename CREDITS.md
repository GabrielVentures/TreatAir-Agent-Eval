# Credits and attribution

This repository describes the artifact and its technical behavior. It does not include private commissioning, recruiting, or meeting material.

The project was developed through collaborative domain and product discussions, with aviation use-case input and feedback on the demonstration. The primary author directed the technical design, simulator integration, action layer, dashboard, evaluation logic, testing, and documentation.

AI coding assistants were used for implementation support, debugging, research organization, and documentation drafting. Generated code was inspected, adapted, and tested against the local simulator. Model outputs and AI assistance do not replace review of the flight traces.

The project includes or relies on:

- X-Plane 12 and its local web API.
- The Laminar Research Airbus A330-300 and its installed navigation data.
- X-Plane SDK headers used to build the optional loader plugin.
- Node.js built-in modules and the OpenAI Responses API or Codex CLI, depending on the selected backend.
